# ClamAV 接入与验收记录

基线：`70890c4c767efd12de7552ddf490671e9b0cf4bd`；分支：`codex/clamav-oem-scanning`。本次修改尚未提交、合并或部署到业务服务器。

## 实现

- 新部署使用 ClamAV 1.4.6 LTS Windows x64 便携组件，随发布包分发。后端通过数字回环地址调用独立 `clamd`，不链接原生库、不增加 NuGet 依赖，不依赖 OfficeScan 探针。保留 `OnAccess` 兼容已有配置，`Fake` 仍仅用于明确选择的测试。
- 上传隔离、文件类型、ZIP/RAR/7z 结构及展开限制保留。流式扫描同时核对上传记录中的大小和 SHA-256，精确的 OK、扫描前后相同的引擎/病毒库版本才能建立通过结果。
- 感染、加密、超限分别处理；服务不可用、超时、异常协议或版本切换均不能放行。病毒库时间按同机 Windows 时区解析，对夏令时歧义作保守处理；扫描审计增加病毒库构建时间和文件 SHA-256。
- ClamAV 模式支持在文件策略页保存病毒库年龄与“过期时暂停放行”门禁；保留已有开关值，不擅自覆盖管理员策略。新部署应在页面启用该门禁（默认年龄参数 48 小时）。不支持时间证明的旧引擎继续显示只读或关闭恢复提示。
- 默认单文件有效扫描上限 1 GiB，上传初始化即拒绝更大文件，不预留配额；管理页说明业务限制与引擎限制取较小值。便携模板限制展开总量 1536 MiB、递归深度 16，并开启超限/加密告警。
- 发布脚本固定官方便携 ZIP 和匹配源码归档的上游 SHA-256，包含许可证、签名、公钥及来源清单。没有 GPG 时明确记录未额外验签，仍强制核对固定的上游摘要。
- 安装为独立 `clamd` / `freshclam` Windows 服务，病毒库和日志不放入网站。初始实现由 FreshClam 联网初始化；后续已按用户要求改为随包内置已验签的 CVD 快照，支持离线首次初始化。FreshClam 保留每日 12 次后续更新检查；详见本次离线病毒库验收记录。
- 新建暂存、程序和数据目录只授予 SYSTEM、Administrators 完全控制；本机隔离 ACL 测试确认该权限传播到子目录和文件。`install-iis.ps1 -UseExistingClamAv` 可显式复用已经安装的同版本服务，但先核对二进制摘要、配置、权限、数据库、服务及端口归属，不重配或启停已有服务。
