# ClamAV 内置病毒库

本次在 `codex/clamav-oem-scanning` 现有修改上继续实现，未改变业务扫描策略或已验证的 API/前端行为，尚未提交、合并或部署业务服务器。

## 部署行为

- 发布包默认内置 `main.cvd`、`daily.cvd`、`bytecode.cvd` 三份官方病毒库，首次安装不再调用 FreshClam 下载。
- 打包和安装共用 `clamav-database.ps1`。固定官方 `sigtool.exe` 摘要，执行数字签名验证，记录文件大小、SHA-256、版本、签名条数、功能级别和 UTC 构建时间；校验和读取期间保持只读共享句柄，防止文件被写入或替换。
- 安装前与复制后分别复验快照和清单；缺失、损坏、清单不符、额外签名库、输入输出路径互相包含、非空目标均拒绝。活动数据库目录只包含三份 CVD，初始快照记录另存于数据根目录。
- ClamD 先加载包内库并就绪，再尝试启动 FreshClam。暂时离线或更新服务启动失败不回滚已就绪扫描器；恢复联网后运行 `update-clamav.ps1` 更新并启动更新服务。
- 内置库不会因复制而重置构建时间。既有“病毒库过期时暂停放行”开关及期限保持不变，过期时仍按策略处理。
