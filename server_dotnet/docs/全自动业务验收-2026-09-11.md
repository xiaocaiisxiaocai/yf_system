## 两项缺陷修复

1. **PDF 兼容性**：真实 Chrome 收到文件及 worker 的 HTTP 200 后仍失败，实际异常为 `n.toHex is not a function`。`pdfEngine.ts` 改为同版本 PDF.js legacy API 与 legacy worker 配对。新增回归直接读取生产引擎的导入，在删除 `Uint8Array.toHex` 的环境中解析真实 PDF 并校验页数和正文；旧实现失败、修复后通过，真实浏览器 canvas 也显示正文。未升级 PDF.js。[PDF.js 官方构建说明](https://github.com/mozilla/pdf.js/blob/master/README.md)说明 legacy 构建用于较旧环境。
2. **Excel 关闭时取消请求**：`ExcelPreview.tsx` 在卸载时终止请求，并在解析前检查组件是否仍有效。迟到响应回归在旧代码中出现一次无效解析，修复后请求已取消且解析次数为零。

相关长期回归：`web/test/pdf-preview.test.cjs`、`web/test/file-security.test.cjs`；PDF 夹具：`web/test/fixtures/pdf-compatibility.pdf`。
