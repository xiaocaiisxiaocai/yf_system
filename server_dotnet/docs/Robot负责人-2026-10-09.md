# Robot 负责人

> 2026-10-09 起生效。补充 [Robot 料号与创建人负责制](Robot料号与创建人负责制-2026-09-23.md) 中主项目公共资料的字段列表。

## 含义

- Robot 负责人是主项目上的一段**自由文本**（通常是人名），仅用于记录和展示。
- 它不关联任何系统账号，不授予项目访问权，不接收邮件提醒，也不参与验收；这些仍只由“负责人”（`responsibleUserId`）、主项目创建人和 `project:view_all` 决定，见 [项目负责人转交与数据字典权限](项目负责人转交与数据字典权限-2026-09-23.md)。

## 项目字段

- 主项目与子项目各有可空列 `robot_owner_name varchar(64)`。迁移 `AddProjectRobotOwnerName` 只加列，不回填历史数据。
- `POST/PUT /api/v1/project-groups` 请求新增 `robotOwnerName`，为必填：trim 后为空返回 400“请填写 Robot 负责人”，超过 64 个字符返回 400“Robot 负责人不能超过 64 个字符”。保存 trim 后的值。
- 历史主项目的 `robotOwnerName` 为空；下一次编辑主项目资料时必须补填。
- 主项目、子项目和列表响应新增 `robotOwnerName`。
- Robot 负责人属于主项目公共资料：新建子项目继承；修改主项目时同步到所有未完成子项目，已完成子项目保留验收时的快照；复制子项目时副本继承主项目当前值。
- 复制前的资料完整性检查包含 Robot 负责人：主项目或源子项目没有 Robot 负责人时，复制返回 409，需先补齐主项目资料。
- 审计：`PROJECT_GROUP_CREATE` 记录 `robotOwnerName`；`PROJECT_GROUP_UPDATE` 的变更列表包含 `robotOwnerName`（标签“Robot 负责人”）。

## 界面

- 主项目新建/编辑表单在“负责人”后显示必填输入框“Robot 负责人”（最多 64 字）。
- 主项目列表在“负责人”列后增加“Robot 负责人”列；主项目标题下摘要行和子项目详情资料中显示 Robot 负责人。
