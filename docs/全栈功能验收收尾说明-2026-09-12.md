## 本轮产品修复

- **匿名未知路由可安全查看 404**：无登录态访问未知地址时显示公共 404，不先跳转登录，也不挂载受保护账号壳或请求受保护数据；点击“返回工作台”后按既有认证规则进入登录页。已登录账号仍在应用壳内显示 404 并可返回工作台。
- **留言失败保留草稿**：留言请求失败由面板收敛，解除发送中状态并保留原草稿，用户可直接重试；成功后才清空输入和刷新列表，不产生假成功或重复留言。
- **留言长度按 Unicode 字符计算**：4000 字上限按 Unicode code point 截断，补充平面字符不会被切成半个代理对；合法 4000 字完整提交和持久化，超限 API 请求仍由后端拒绝且不写入。

```powershell
Push-Location .\web
try {
  npm test
  npm run lint
  npm run build
} finally { Pop-Location }

Push-Location .\server_dotnet
try {
  dotnet test --project .\tests\Yf.Api.Tests.csproj
  dotnet build .\TestHost\Yf.Api.TestHost.csproj --no-restore
  python .\scripts\test-isolated.py

  $env:YF_PLAYWRIGHT_RUNNER = 'C:\你的工具目录\playwright-skill\run.js'

```
