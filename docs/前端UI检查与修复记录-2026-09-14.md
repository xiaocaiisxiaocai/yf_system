# 前端 UI 检查与修复记录

日期：2026-09-14。范围为当前 React / Arco 前端，不涉及 Rust、数据库初始化或业务权限调整。

## 检查范围

对登录、修改密码、工作台、个人资料、项目列表、项目详情、供应商、用户、组织架构、角色权限、操作日志、系统参数、404 共 13 个路由进行源码审查及隔离浏览器检查。

基础矩阵为 1440×900、390×844，共 26 个页面与视口组合；另验证 721/800px 中间断点、390×360/800×360 短屏、长名称、展开项目说明及校验错误。覆盖主要表单、下拉菜单、供应商账号抽屉、权限抽屉、文件上传、留言回执及成员弹层。

浏览器使用当前应用的真实组件和 Vite 样式，接口由 Playwright 在独立浏览器上下文中模拟；未匹配的 API 中止。该检查证明页面布局和指定交互，不等同于真实账号、邮件投递、文件上传或完整业务端到端验收。

## 已修复

| 问题 | 修复与证据 |
| --- | --- |
| 组织“更多”按钮使用原生 details/summary 和文本箭头，尺寸、对齐及关闭交互与其他按钮不同 | 改为 Arco Button、IconDown、Dropdown/Menu；高度 32px，图标与文字中心一致；验证点击外部和 Esc 关闭。危险操作进入独立确认框。 |
| 组织删除的旧回调可能清空后来选择的另一个节点 | 使用函数式状态更新，仅清除被删节点；回归覆盖确认框固定原节点及切换节点后的状态。 |
| 项目新建/编辑弹窗关闭了自动聚焦 | 移除 autoFocus=false，恢复组件默认焦点管理。 |
| 供应商账号子弹窗与父抽屉争抢焦点 | 新增/编辑账号或重置密码弹窗打开时，暂停父抽屉焦点锁及关闭入口；子弹窗关闭后恢复。保留原有表单和取消清空行为。 |
| 留言“已读人员”入口为不可聚焦的文本 | 改为带无障碍名称的原生按钮，保留计数、状态颜色和回执重试能力。 |
| 多个点击弹层未统一启用 Esc 关闭 | 通过 ConfigProvider 的 Trigger 配置统一启用，组织菜单及回执入口也明确配置。 |
| 密码显示/隐藏按钮点击区域只有 12×12px | 扩大为 24×24px，保持图标尺寸和表单布局。 |
| 登录/改密页固定高度且隐藏溢出，短屏校验后表单被裁剪 | 使用动态视口最小高度，允许内容增高；短屏给品牌预留顶部空间。修前 390×360/800×360 表单 top=-21、bottom=381 且文档仅 360px；修后文档可滚动到全部内容。 |
| 项目列表缺少横向滚动的最小列宽 | 横向宽度按实际列宽总和计算，保护窄屏操作列可达性。 |
| 移动工具栏首项样式选择器未命中实际 Space 层级 | 修正选择器，使搜索框占据完整首行，筛选项正常换行。 |
| 721–900px 保留侧栏与双列，组织详情过窄 | 该宽度范围收起侧栏并提供导航按钮，个人资料改为单列。721px 下组织详情从 151px 恢复到 351px。 |
| 长项目说明展开后将动态列表压到 0 高度 | 动态面板保留最小高度，外层允许滚动；短屏改为正常文档流。实测受影响断点的动态内容区恢复到 220–237px。 |

## 验证

- 前端自动化测试：140 项通过，0 失败、0 跳过。新增确认边界回归，更新已读入口的语义定位，保留旧响应和跨项目隔离断言。
- 前端生产构建通过。
- lint 完成，保留既有 form-contracts 测试夹具的 no-children-prop 提示。
- 基础浏览器矩阵 26/26 完成，稳定态页面/内容横向溢出 0、弹层裁剪 0，未匹配 API 和控制台/页面错误均为 0。
- 键盘与焦点专项 9/9 通过，包含项目弹窗、留言已读入口、账号菜单、供应商三个子弹窗及系统参数下拉。
- 有意横向滚动的表格不计为页面溢出；抽屉等待动画结束并确认焦点进入后再测量/关闭。不将标题定位失败、动画中间位移等脚本误报当作应用缺陷。
- 未覆盖真实后端持久化、全部权限组合、文件上传/预览/下载的提交结果、全部失败态及未知超长日志动作名。
- 本轮没有对真实业务数据、SMTP、系统参数或用户权限进行写入。
