## 确认的问题与处理

| 问题 | 触发及影响 | 修复与验证 |
|---|---|---|
| 系统参数保存竞态 | 保存请求或刷新未结束时继续编辑，成功回调清空全部草稿；写入成功但刷新失败时显示状态不准确 | 保存期间冻结普通参数编辑，按提交快照清理已保存值，刷新失败明确提示已保存；deferred 回归覆盖，SMTP 草稿保留 |
| 项目未读角标回退 | 已读后的新摘要先返回，首屏旧摘要稍后返回，将未读数重新写大 | 首屏与后续摘要共享请求序号，丢弃迟到结果；deferred 回归验证角标不会复活 |
| 内置角色可被误删 | 无绑定账号时删除内置供应商角色，后续创建供应商账号报 500 且没有 API 恢复入口 | 后端拒绝删除内置角色，前端隐藏删除入口；HTTP 验证零绑定也不能删除、角色/权限不变、随后创建供应商账号成功；自定义角色删除保留 |
| IIS 安装配置覆盖 | 环境变量优先于外部 JSON；安装未检查继承来源，可能连到非预期数据库 | 安装写入前检查包和继承环境；新专属池明确使用应用池身份且不加载用户配置；维护复用守卫。纯守卫、真实维护集成与本机只读 IIS 探针验证，未部署站点 |
| 测试使用旧后端 | API 已重编译，但 TestHost 目录仍是旧程序集，主体 HTTP 测试可能对旧代码通过 | 启动前比较实际 API/托管依赖字节，并记录实际加载制品；陈旧/缺失依赖临时样本回归、真实 HTTP 复跑通过 |
| 关闭断言仍可能报告通过 | Python 优化模式会移除恢复或持久化验证中的 assert | HTTP、浏览器和维护入口拒绝关闭断言；维护入口在导入数据库客户端前拒绝，两种优化开启方式均已验证 |
| 浏览器步骤空跑 | 某一步退出码为 0，但没有新增操作记录，编排仍可能标记成功 | 每步检查新增证据；认证检查、fixture 关键结构及样本分别校验，其他步骤至少追加一个成功操作组；空步骤、失败记录、改写旧证据的纯回归通过 |

- 本轮完成自动化组件/数据库/HTTP/维护测试及实际页面局部检查，未重跑完整浏览器业务验收脚本。两个前端竞态由受控延迟响应的组件测试证明；页面空数据浏览不能替代完整业务链路验证。
- 没有发送真实 SMTP 邮件，没有执行目标服务器 IIS 安装、升级、恢复或证书操作。本机 IIS 只读探针不代表目标服务器部署成功。
- `ApiContractTests` 的路由清单只证明方法/路径，业务字段和权限另由 HTTP 回归支撑；不宣称穷尽所有输入组合。
- 数据库连接未设置时部分 xUnit 用例会主动跳过；完整验收须显式提供隔离连接并确认跳过数为零。本轮实际为零跳过。
- 浏览器编排新增的每步证据门禁用于拒绝空跑，不等同于每个业务操作都已具备独立覆盖清单。现有全局浏览器错误门禁主要覆盖页面异常和非预期 5xx，不将其解释为“所有网络/控制台问题均不存在”。

- 供应商账号抽屉在子表单请求期间关闭时，请求仍会继续；本轮将其视为交互边界，没有改变已授权请求的提交语义。
