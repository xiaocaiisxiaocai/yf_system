## agy 意见的复核取舍

agy 的截图意见是复核线索，不直接等于缺陷。以下代表性意见没有盲目落实：

| 意见或现象 | 复核结论 |
|---|---|
| 将预览补上下载按钮、给 Excel 测试图片判为损坏、把只读 Excel 当在线编辑器 | 与用户要求或夹具事实不符；预览继续不提供下载，粉/青图块是有意嵌入的测试图片。 |
| 首次/重置密码提示旁缺 Checkbox | 这是强制改密策略说明，不是用户可切换配置；不新增开关。 |
| 回执人数不一致、角色点数与未保存勾选不同 | 前者是初始夹具不一致，已修正；后者是用例主动取消选择且尚未保存。业务统计与权限回显不据此修改。 |
| 活动 Tab 未切换、匿名访问白屏、弹窗箭头远离按钮 | 补齐异步渲染和动画等待后复验；实际可正常切换/重定向，箭头与触发按钮对齐。早期中间帧不作为产品缺陷。 |
| 邮件队列或日志复制按钮在手机端消失 | 滚动后可达，复制脱敏验证通过；不能把首屏之外的内容判为不存在。 |
| 表格只用部分卡片宽度、对象列被截断、系统参数第一列只剩字母 | 实际表格尺寸正常，部分图为横向滚动位置或固定列遮挡的截面；已验证横向可达与完整内容。 |
| 下拉菜单遮住后景、聚焦按钮有底色、快速连续操作时前一 Toast 尚未消失 | 属于可关闭浮层、焦点或短暂反馈；明确区分与本轮修复的单次请求重复提示，不移除必要状态反馈。 |
| 文件批量删除缺入口；前端没有硬编码 accept/大小/数量限制 | 当前产品没有批量删除要求；一次选择一个文件，类型及大小由 ASP.NET Core UploadService 初始化接口按系统参数校验。不新增批量删除、固定阈值或项目/用户配额。 |
| 要求所有操作按钮左对齐、重做空态/配色/图标、强行填满 Excel 空白列 | 属于设计取舍；保留现有 Arco 风格、操作列约定与原文件展示，不因审美建议扩大改动。 |

## 验证边界

- 浏览器操作使用本机开发前端，所有测试 API 由内存夹具截获或阻止；保存、删除、上传、邮件与账号状态测试没有写入真实业务数据库。它们证明前端布局、请求及反馈，不替代后端持久化或生产环境验收。
- 有意返回的 400/404/500 已与非预期运行错误分开；早期定位错误、截图时机、无日期的旧截图、debug/failure 图不当作通过证据。日志日期已补真实日历选择与 start/end 请求断言；手机端日志复制已验证脱敏。
- 预览使用本地 PDF/XLSX 夹具；没有发送客户文档、真实密码或 SMTP 授权码给 agy。
- Rust 和已有部署文件的 8 项未提交改动经 SHA-256 核对均保持原样。本轮修改限于前端与报告，未合并 main。
