## 已确认修复范围

- **数值查询参数严格拒绝**：分页及 `departmentId`、`targetId` 等数值参数在为空、重复、负数、非数字或溢出时返回既有 `400 / 40001`，不再回退默认值或取消过滤，避免错误输入扩大查询结果。
- **上传统一使用数据库 UTC**：上传查询、分片、合并及维护恢复以 MySQL `UTC_TIMESTAMP(6)` 为过期权威，避免应用机与数据库时钟偏差导致有效会话被误删或已过期会话被恢复。过期的失联 `MERGING` 会话不能重新发起合并，已完成上传仍支持幂等重试。
- **表单 Unicode 长度一致**：前端按 Unicode 字符而非 UTF-16 code unit 计算姓名、项目名称等长度，使包含代理对字符的输入与后端验证结果一致。
- **留言已读与异步上下文隔离**：`MessagePanel` 采用服务端返回的权威已读计数，并隔离旧项目、旧留言和已关闭详情的迟到响应，避免切换上下文后被旧请求覆盖。
- **供应商账号抽屉刷新竞态**：同一供应商的多个账号并发启停后，只允许最新刷新请求更新列表与错误状态，避免迟到结果覆盖新状态。切换供应商仍沿用原有独立组件实例。

本轮没有增加产品功能，也没有恢复已删除的旧轮次或旧编码需求。
