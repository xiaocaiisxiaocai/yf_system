# 相同密码改密修复记录

日期：2026-09-14

首次登录时提交与初始密码相同的新密码，原实现会重新保存密码并解除首次改密限制。原因是自助改密接口只验证原密码与新密码强度，缺少新旧密码比较；首次改密、个人资料改密两个页面也没有相应检查。

## 修复行为

- 后端在验证原密码正确之后比较新旧密码，相同时返回 HTTP 400：`新密码不能与当前密码相同`。
- 拒绝时不修改密码、首次改密标记、登录失败计数、锁定状态、更新时间、审计记录及会话。
- 两个页面在提交前显示相同提示，保留当前表单和登录状态。
- 不同且符合现有规则的新密码仍可保存，成功后撤销旧会话并要求重新登录。保留 6–20 位及弱密码校验，不增加历史密码限制。
