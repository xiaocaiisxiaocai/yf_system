# 操作日志优化与验证记录

日期：2026-09-14

范围：ASP.NET Core 后端审计记录、操作日志列表与详情。保留现有 Arco 设计系统，不修改角色权限、项目验收规则或历史业务数据。

## 已完成

- 新日志保存操作人姓名、对象名称、来源类型、请求 ID；HTTP 操作按现有可信代理规则补齐 IP。
- 用户、角色、组织、供应商、供应商账号、个人邮箱、项目说明及安全系统参数记录实际修改前后值；未变化的字段不列为变更。
- 角色授权记录新增、移除权限的 ID、编码、名称；项目成员调整记录新增、移除成员的 ID、工号、姓名。
- SMTP 只记录服务器、端口、登录账号、发件邮箱、加密方式的变更；密码或授权码仅记录是否更新，不记录内容。
- 日志搜索覆盖工号、姓名、对象名称、操作编码及已记录的详情，包括历史名称快照。
- 详情抽屉分为操作概览、变化明细、原因说明、来源信息和默认收起的原始数据。支持原始数据复制及失败反馈。
- 列表分类与具体操作联动；修复无意义的权限摘要、遗漏的驳回原因及表格横向宽度。
- 统一详情的字体、边距、细边框和窄屏布局；长名称、长说明可换行。

## 历史记录与边界

- 不执行数据库结构迁移，不回填或推测历史变更。
- 新日志优先展示操作时快照；旧日志已有详情名称继续使用。只能关联到当前名称的记录会标为“当前名称（历史辅助）”。
- 旧权限记录只有 ID 时可计算实际增减 ID，但不冒充已知当时的名称或编码。
- 旧日志没有前后值时明确提示缺失；新日志保存但未产生变化时显示“未发生字段变化”。
- 系统任务没有 IP 或请求 ID 时显示“不适用”，已有历史 IP 仍正常显示。
- UI 显示及复制原始数据时递归隐藏敏感键；敏感字段形式的 before/after 值也隐藏。后端写入端仍以明确的安全字段清单为准。

## 字体反馈修正
